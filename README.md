# LyricSide

Aplicativo Android para aprender inglês com músicas.

## O que já funciona

- letra em inglês e português lado a lado;
- biblioteca salva localmente no celular;
- tradução automática quando há internet;
- leitura offline das músicas já salvas;
- áudio local opcional;
- controles de velocidade e ±5 segundos;
- modo só inglês, só português e modo de estudo;
- marcação de frases difíceis com ★;
- aba de revisão;
- favoritos, anotações e backup.

## APK

O GitHub Actions compila automaticamente um APK de teste a cada atualização da branch `main`.
Abra a aba **Actions** ou **Releases** para baixar `LyricSide-v2.apk`.

> O APK atual é uma compilação debug, adequada para instalação pessoal e testes.
